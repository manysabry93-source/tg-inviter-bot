# 🤖 ربات تلگرامی فراهوش

ربات کاملاً **رایگان و بدون سرور** (Cloudflare Workers) با پنل ادمین زنده داخل تلگرام.

---

## ✅ چیزهایی که از قبل لازم داری
1. یک اکانت [Cloudflare](https://dash.cloudflare.com/sign-up) (رایگان)
2. اکانت گیت‌هاب (داری ✅)
3. توکن ربات از [@BotFather](https://t.me/BotFather) در تلگرام
   - به BotFather پیام بده: `/newbot`
   - یک اسم و یک username (باید به `bot` ختم بشه، مثلاً `farahoosh_bot`) بده
   - یک توکن شبیه `123456:ABC-DEF...` بهت می‌ده — نگهش دار

---

## 🚀 مراحل راه‌اندازی (فقط یک‌بار)

### ۱. آپلود کد به گیت‌هاب
یک ریپازیتوری **خصوصی (Private)** جدید بساز و این پوشه رو داخلش push کن:
```bash
cd telegram-bot
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/farahoosh-bot.git
git push -u origin main
```

### ۲. نصب Wrangler و ورود به Cloudflare
```bash
npm install
npx wrangler login
```
(یک تب مرورگر باز می‌شه، اجازه بده)

### ۳. ساخت دیتابیس KV
```bash
npx wrangler kv namespace create "BOT_DB"
```
خروجی یک چیزی شبیه این می‌ده:
```
id = "abcd1234efgh5678..."
```
این `id` رو کپی کن و داخل فایل `wrangler.toml` جای `REPLACE_WITH_YOUR_KV_ID` بذار.

### ۴. تنظیم توکن ربات (به‌صورت امن، نه در کد)
```bash
npx wrangler secret put BOT_TOKEN
```
توکنی که از BotFather گرفتی رو پیست کن و Enter بزن.

### ۵. تنظیم آیدی عددی ادمین
- ربات رو در تلگرام Start کن، بعد پیام `/myid` رو بفرست تا آیدی عددی خودت رو ببینی.
- این عدد رو داخل `wrangler.toml` جای `ADMIN_IDS = "111111111"` بذار (اگه چند ادمین داری با کاما جدا کن: `"111,222"`)

### ۶. دیپلوی اولیه (دستی، یک‌بار)
```bash
npx wrangler deploy
```
بعد از اجرا، یک آدرس مثل این بهت می‌ده:
```
https://farahoosh-bot.YOUR-SUBDOMAIN.workers.dev
```

### ۷. فعال‌سازی webhook (فقط یک‌بار، کافیه در مرورگر باز کنی)
آدرس زیر رو در مرورگر باز کن (به‌جای YOUR-SUBDOMAIN آدرس واقعی خودت رو بذار):
```
https://farahoosh-bot.YOUR-SUBDOMAIN.workers.dev/setup
```
اگه پیام `"ok": true` دیدی، تمام — ربات فعاله! 🎉

## 🔁 دیپلوی خودکار با هر تغییر (GitHub Actions)
برای این‌که از این به بعد فقط با `git push` آپدیت بشه:

1. از داشبورد Cloudflare، بخش **My Profile > API Tokens** یک توکن با دسترسی **Edit Cloudflare Workers** بساز.
2. در گیت‌هاب، به ریپازیتوری برو: **Settings > Secrets and variables > Actions**
3. دو Secret بساز:
   - `CF_API_TOKEN` = توکنی که ساختی
   - `CF_ACCOUNT_ID` = از داشبورد Cloudflare، سمت راست صفحه‌ی Workers قابل مشاهده است

از این به بعد هر `git push` به شاخه‌ی `main`، خودش دیپلوی می‌شه.

## 🛠 استفاده از پنل ادمین
داخل تلگرام (فقط برای آیدی‌های داخل `ADMIN_IDS`):
- `/admin` → منوی مدیریت باز می‌شود
- **مدیریت دکمه‌ها** → عنوان/لینک هر دکمه رو عوض کن یا فعال/غیرفعال کن
- **ارسال اطلاعیه** → پیام رو بنویس، برای همه‌ی کاربرانی که ربات رو استارت کردن ارسال می‌شه
- **آمار ربات** → تعداد کاربران فعلی

## 🧩 ساخت دکمه‌ی دلخواه (موتور منوی پویا)
از `/admin` → **🧩 مدیریت دکمه‌ها** وارد می‌شوید. در هر سطحی از منو می‌توانید:
- **➕ افزودن دکمه جدید** بزنید، عنوان را بنویسید، و نوعش را انتخاب کنید:
  - 🔗 **لینک** — با کلیک مستقیم در مرورگر باز می‌شود (متن لینک به کاربر نمایش داده نمی‌شود)
  - 📝 **متن ساده** — یک متن ثابت نمایش می‌دهد
  - 📋 **فرم** — سوالات دلخواه خودتان را یکی‌یکی بفرستید؛ در پایان بنویسید `/done`. جواب‌های کاربر برای شما ارسال می‌شود
  - 📱 **درخواست شماره تماس** — کاربر با یک دکمه‌ی تلگرامی شماره‌اش را برای شما می‌فرستد
  - 📂 **زیرمنو** — یک دکمه‌ی جدید که با کلیک، مجموعه‌ای از دکمه‌های دیگر را باز می‌کند (می‌توانید هر عمقی از زیرمنو بسازید)
  - 📡 **اتصال به کانال** — یک کانال تلگرامی وصل می‌کنید؛ سپس هر «محتوا»یی که داخلش تعریف کنید با فوروارد کردن از همان کانال ساخته می‌شود (دقیقاً مثل بخش ویدیو، ولی برای هر کانالی که بخواهید). مناسب وقتی چند محتوا از یک کانال ثابت دارید.
  - 📎 **فایل (عکس/ویدیو/سند)** — یک یا **چند** فایل را مستقیماً به ربات آپلود یا فوروارد می‌کنید (بدون نیاز به کانال)؛ با کلیک کاربر روی این دکمه، **همه‌ی** فایل‌ها پشت‌سرهم برایش ارسال می‌شوند. از داخل صفحه‌ی ویرایش دکمه («📂 مدیریت فایل‌ها») هر زمان می‌توانید فایل اضافه کنید، حذف کنید یا جایگزین کنید.
  - ❓ **سوال ناشناس** — کاربر سوال می‌پرسد، بدون افشای هویتش برای شما
- روی هر دکمه‌ی موجود بزنید تا: عنوانش را عوض کنید، محتوایش را عوض کنید، فعال/غیرفعال‌اش کنید، یا حذفش کنید (حذف یک زیرمنو، همه‌ی زیرشاخه‌هایش را هم حذف می‌کند — قبلش یک پیام تاییدیه می‌آید)

### چیدمان تک‌ستونی یا دوستونی
روی هر **زیرمنو** (یا خود منوی اصلی) که بزنید، یک گزینه‌ی «🔢 چیدمان فعلی: تک ستونی/دو ستونی» می‌بینید — با زدنش بین حالت یک دکمه در هر ردیف و دو دکمه در هر ردیف سوییچ می‌کند. این تنظیم مخصوص همان زیرمنو است.

## 📁 مدیریت محتوا (پیش‌نمایش، حذف، جایگزینی)
از `/admin` → **📁 مدیریت محتوا**، تمام محتوای رسانه‌ای ثبت‌شده در کل ربات — فایل‌های روی دکمه‌ها، محتوای متصل به کانال‌ها، و ویدیوهای آموزشی — بر اساس نوع (عکس/ویدیو/سند/صدا/ویس/محتوای کانال) دسته‌بندی و شمارش شده نمایش داده می‌شود. با زدن روی هر مورد، پیش‌نمایشش را می‌بینید و می‌توانید حذفش کنید یا (برای فایل‌های روی دکمه) جایگزینش کنید.

برای افزودن ویدیوی آموزشی جدید (رشته/مقطع/درس)، دکمه‌ی **🎥 افزودن ویدیوی آموزشی جدید** در همان پنل اصلی همچنان در دسترس است.

## 📢 ارسال اطلاعیه (نسخه‌ی کامل)
از `/admin` → **📢 ارسال اطلاعیه**:
1. متن، یا یک عکس/ویدیو/سند (با کپشن دلخواه) بفرستید
2. اگر خواستید یک دکمه‌ی لینک هم زیر پیام اضافه شود، آدرسش را بفرستید و بعد متن دکمه را بنویسید؛ در غیر این صورت بنویسید `/skip`
3. پیام بلافاصله برای همه‌ی کاربرانی که ربات را استارت کرده‌اند ارسال می‌شود — بدون نیاز به هیچ اقدامی از طرف کاربر

## 📊 آمار ربات
علاوه بر تعداد کل کاربران، آیدی عددی تمام کاربران هم نمایش داده می‌شود (در صورت زیاد بودن تعداد، در چند پیام جداگانه ارسال می‌شود).

## 🔐 کنترل دسترسی هر دکمه (جداگانه)
روی هر دکمه (به‌جز منوی اصلی) که بروید، گزینه‌ی **🔐 کنترل دسترسی** را می‌بینید. سه حالت وجود دارد:
- **🌍 همه** — بدون محدودیت (پیش‌فرض)
- **👥 لیست خاص** — فقط کاربرانی که آیدی عددی‌شان را اضافه کرده‌اید می‌بینند و می‌توانند از این دکمه استفاده کنند؛ برای بقیه‌ی کاربران، دکمه اصلاً در منو نمایش داده نمی‌شود.
- **✅ با تایید ادمین** — همه دکمه را می‌بینند؛ با کلیک، کاربر باید یک فرم (قابل تعریف توسط شما، پیش‌فرض: نام/رشته/مقطع/شماره) را پر و ارسال کند. درخواست برای یک چت مشخص (پیش‌فرض: خودتان؛ قابل تغییر به هر آیدی دیگری) با دو دکمه‌ی ✅ تایید / ❌ رد ارسال می‌شود. با تایید، آن کاربر برای همیشه به دکمه دسترسی پیدا می‌کند.

با زدن روی «حالت فعلی» بین این سه حالت سوییچ می‌کنید. برای حالت‌های «لیست خاص» و «با تایید ادمین»، از همان صفحه می‌توانید کاربران مجاز را مدیریت کنید (افزودن/حذف با آیدی عددی).

## 🔒 دسترسی اجباری (عضویت در کانال + شماره تماس)
از `/admin` → **🔒 دسترسی اجباری (کانال/شماره)**:
- **➕ افزودن کانال جدید** — نام کاربری کانال را بدون یا با @ بفرستید. ⚠️ **مهم:** ربات باید عضو یا ادمین آن کانال باشد، وگرنه نمی‌تواند عضویت کاربران را بررسی کند.
- هر کانالی که اضافه کنید، برای همه‌ی کاربران (غیر از ادمین‌ها) اجباری می‌شود — تا عضو نشوند، هیچ بخشی از ربات برایشان کار نمی‌کند.
- **📱 الزام ارسال شماره تماس** — با یک کلیک فعال/غیرفعال می‌شود. وقتی فعال باشد، کاربر تا شماره‌اش را نفرستد نمی‌تواند از ربات استفاده کند.
- **✏️ ویرایش متن درخواست شماره** — متنی که هنگام درخواست شماره به کاربر نشان داده می‌شود را عوض کنید (پیش‌فرض: توضیح این‌که شماره فقط برای مشاور مرتبط با رشته‌اش استفاده می‌شود).
- اگر هیچ کانالی اضافه نکنید و شماره را هم الزامی نکنید، ربات کاملاً آزاد باقی می‌ماند (پیش‌فرض).

❕ **محدودیت واقعی:** لایک کردن پست یا گذاشتن ری‌اکشن قابل تایید توسط ربات نیست — تلگرام این اطلاعات را در اختیار ربات‌ها نمی‌گذارد، به همین دلیل عمداً پیاده‌سازی نشده.

## 🤖 اتصال دکمه به هوش مصنوعی
### تنظیم اولیه (یک‌بار)
از `/admin` → **🤖 تنظیمات هوش مصنوعی**:
- **🔗 آدرس API (Base URL)** — آدرس یک سرویس سازگار با فرمت OpenAI (خود OpenAI، یا OpenRouter، DeepSeek، و مشابه؛ پیش‌فرض: `https://api.openai.com/v1`)
- **🔑 کلید API** — کلیدی که از همان سرویس گرفته‌اید (⚠️ در دیتابیس ربات ذخیره می‌شود)
- **🧠 نام مدل** — مثلاً `gpt-4o-mini` (برای تحلیل عکس، مدل باید از ورودی تصویر پشتیبانی کند)

### ساخت دکمه
موقع ساخت دکمه‌ی جدید، نوع **🤖 هوش مصنوعی (چت با AI)** را انتخاب کنید. می‌توانید یک دستورالعمل اختصاصی (system prompt) برای همان دکمه بدهید (مثلاً «فقط به سوالات فیزیک جواب بده») یا با `/skip` از حالت پیش‌فرض (دستیار آموزشی عمومی) استفاده کنید. این دکمه هم مثل بقیه‌ی دکمه‌ها از **🔐 کنترل دسترسی** (همه/لیست خاص/تایید ادمین) پشتیبانی می‌کند.

با کلیک کاربر روی این دکمه، یک گفتگوی زنده شروع می‌شود: کاربر می‌تواند سوال بپرسد یا عکس (مثلاً عکس یک سوال درسی) بفرستد تا تحلیل و رفع اشکال شود؛ ربات کل مکالمه را به‌خاطر می‌سپارد تا وقتی کاربر «🔙 پایان گفتگو» را بزند. تحلیل عکس روی روبیکا فعلاً پشتیبانی نمی‌شود (فقط متن).

## 🌐 پشتیبانی چندپلتفرمی (تلگرام + بله + روبیکا)
این ربات الان روی سه پلتفرم قابل اجراست — با همین یک کد و همین یک Cloudflare Worker، ولی هرکدوم کاملاً مستقل (کاربرها، منو، تنظیمات هرکدوم جدا از بقیه ذخیره می‌شود؛ یعنی باید پنل ادمین هرکدوم را جدا تنظیم کنید).

### ✅ بله (Bale) — کاملاً پیاده‌سازی شده
API بله عملاً کپی سازگار API تلگرام است، پس همه‌ی امکانات (منوی پویا، پنل ادمین، گیت دسترسی، مدیریت محتوا، Broadcast، ویدیوی اختصاصی) به همان شکل کار می‌کنند.

راه‌اندازی:
1. در بله به **@botfather** پیام بده، `/newbot` بزن، توکن بگیر
2. `npx wrangler secret put BALE_BOT_TOKEN` و توکن را پیست کن
3. در `wrangler.toml`، `BALE_ADMIN_IDS` را با آیدی عددی خودت در بله جایگزین کن (با `/myid` در ربات بله‌ات پیدا می‌کنی)
4. بعد از دیپلوی، آدرس `https://.../setup/bale` را در مرورگر باز کن

### ⚠️ روبیکا (Rubika) — پیاده‌سازی شده ولی نیاز به تست واقعی دارد
API روبیکا ساختار کاملاً متفاوتی دارد (آیدی‌ها به‌جای عدد، رشته‌های GUID هستند؛ کیبورد و کلیک دکمه‌ها مکانیزم متفاوتی دارند). یک لایه‌ی سازگاری کامل نوشته شده که پیام‌های ورودی/خروجی روبیکا را به همان شکلی تبدیل می‌کند که بقیه‌ی کد می‌فهمد — ولی چون به یک اکانت واقعی روبیکا دسترسی ندارم، **نتوانستم آن را با ترافیک واقعی تست کنم.**

محدودیت‌های شناخته‌شده روی روبیکا:
- «ویدیوی آموزشی» و «اتصال به کانال» غیرفعالند (روبیکا معادل forward/copy از کانال برای بات‌ها ندارد)
- «عضویت اجباری در کانال» (بخش گیت دسترسی) غیرفعال است؛ فقط «الزام شماره تماس» کار می‌کند

راه‌اندازی:
1. در روبیکا به **@botfather** پیام بده و ربات بساز، توکن بگیر
2. `npx wrangler secret put RUBIKA_BOT_TOKEN`
3. `RUBIKA_ADMIN_IDS` را در `wrangler.toml` با آیدی خودت در روبیکا (که به شکل GUID است، نه عدد) جایگزین کن — اولین پیامی که به ربات می‌فرستی را با `/myid` بگیر
4. `https://.../setup/rubika` را باز کن

**بعد از تست اول:** اگر پیامی نیومد یا فرمت عجیب دیدی، از داشبورد Cloudflare → Workers → Logs، خروجی خام (raw body) پیام‌های روبیکا را ببین و برام بفرست تا لایه‌ی سازگاری (`src/platforms/rubika.js`) را با فرمت واقعی تطبیق بدم — این طبیعیه و بخشی از فرآیند تست یک پلتفرم جدیده.

### ❌ ایتا (Eitaa) — ساخته نشد
API رسمی ایتا (eitaayar.ir) فقط برای ارسال پیام/فایل یک‌طرفه طراحی شده، نه یک ربات تعاملی با دکمه و منو. اگر مدرک یا مستندات دیگه‌ای از یک API تعاملی‌تر برای ایتا داری، بفرست تا بررسی کنم.

## 🎥 اضافه کردن ویدیوهای آموزشی
فعلاً افزودن ویدیو از طریق KV مستقیم انجام می‌شه (در نسخه‌ی بعدی یک UI کامل برای این هم داخل پنل ادمین اضافه می‌کنم). ساختار داده به این شکل است:

```json
{
  "fields": ["تجربی", "ریاضی", "انسانی", "متوسطه اول"],
  "grades": ["دهم", "یازدهم", "دوازدهم"],
  "videos": {
    "تجربی": {
      "دهم": [
        { "title": "زیست‌شناسی - فصل ۱", "messageId": 45 },
        { "title": "شیمی - فصل ۱", "messageId": 52 }
      ]
    }
  }
}
```
`messageId` یعنی شماره‌ی پیام ویدیو داخل کانال `@fara_video` (روی پیام در تلگرام دسکتاپ راست‌کلیک کن → Copy Message Link → عدد آخر لینک همون messageId است).
